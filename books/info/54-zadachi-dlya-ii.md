## Задачи для ИИ: промпт как ТЗ (2–3 рабочих шаблона)

«Напиши текст», «сделай отчёт», «придумай идеи» — ИИ возвращает что-то общее или не то. Промпт без структуры = лотерея. Промпт как ТЗ: контекст, задача, формат выхода, ограничения — и результат предсказуемее.

### Типичная картинка

Монокарп пишет в чат с ИИ:

> **Монокарп:** Напиши описание нашего продукта для сайта.  
> **ИИ:** [общее описание на 500 слов, без конкретики]  
> **Монокарп:** Не то. Нужно короче и про интеграции.  
> **ИИ:** [ещё один вариант, снова не то]  
> **Монокарп:** Ты что, не понимаешь?

ИИ не знает: какой продукт, для кого сайт, какой тон, какой объём. Промпт размыт — результат случайный.

Безсифона просит ИИ:

> **Безсифона:** Напиши письмо соседям про собрание.  
> **ИИ:** [формальное письмо на полстраницы]  
> **Безсифона:** Слишком длинно. И тон не тот — мы же соседи.  
> **ИИ:** [короткое, но слишком неформальное]  
> **Безсифона:** Опять не то.

Контекст, тон, объём — не заданы. ИИ угадывает.

### Что не так

- **Нет контекста** — что за продукт, кто аудитория, что уже есть.
- **Нет формата выхода** — объём, структура, тон.
- **Нет ограничений** — чего избегать, что обязательно включить.
- **«Напиши», «сделай»** — действие есть, границы нет.

### Рабочий вариант

> «Промпт для ИИ — это ТЗ. Контекст + задача + формат + ограничения.»

Паттерн:

> **Шаблон промпта: 1) Контекст (что есть, для кого, зачем). 2) Задача (что сделать). 3) Формат выхода (объём, структура, тон). 4) Ограничения (чего избегать, что обязательно).**

Шаблон 1 — текст:

```
Контекст: [продукт/ситуация], аудитория [кто], цель [зачем].
Задача: [что написать].
Формат: [объём], [структура], тон [какой].
Ограничения: не упоминать X, обязательно включить Y.
```

Шаблон 2 — структурированные данные:

```
Контекст: [источник данных], [что с ними делаем].
Задача: [извлечь/преобразовать/сгруппировать].
Формат выхода: [таблица/список/JSON], поля [какие].
Ограничения: [что пропустить, что обязательно].
```

### Сравним

**Было**

> «Напиши описание нашего продукта для сайта.»

**Стало**

> «Контекст: продукт — платформа для приёма платежей, аудитория — малый бизнес, цель — лендинг для привлечения клиентов.  
> Задача: написать описание продукта для главной страницы сайта.  
> Формат: 2–3 абзаца, до 300 слов, тон — понятный, без жаргона.  
> Ограничения: не упоминать цены, обязательно — простота интеграции и скорость подключения.»

**Было**

> «Напиши письмо соседям про собрание.»

**Стало**

> «Контекст: собрание жильцов, тема — благоустройство двора, соседи — знакомые, не формальные.  
> Задача: написать приглашение на собрание.  
> Формат: короткое сообщение, 3–5 предложений, тон — дружелюбный, по-соседски.  
> Ограничения: дата, время, место — обязательно; без канцелярита.»

### Что проверить перед отправкой

- Есть ли **контекст** — что, для кого, зачем?
- Есть ли **задача** — что сделать?
- Есть ли **формат выхода** — объём, структура, тон?
- Есть ли **ограничения** — чего избегать, что обязательно?

### Проверь себя

**Вопрос 1.** Нужно попросить ИИ написать текст. Что обязательно включить в промпт?

- **A.** Только «напиши X».  
- **B.** Контекст + задача + формат выхода + ограничения.  
- **C.** Длинное описание без структуры.  
- **D.** «Сделай хорошо.»

**Вопрос 2.** ИИ вернул не то. Что могло пойти не так?

- **A.** ИИ глупый.  
- **B.** Промпт не содержал контекста, формата или ограничений — ИИ угадывал.  
- **C.** Нужно было попросить по-другому.  
- **D.** ИИ не подходит для таких задач.

**Баллы:** Вопрос 1: A — 0, B — 2, C — 0, D — 0. Вопрос 2: A — 0, B — 2, C — 0, D — 0.
