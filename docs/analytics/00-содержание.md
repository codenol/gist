# Структурированный промптинг для ИИ: Содержание

> **Цель:** Дать UX/UI дизайнерам (в первую очередь), а аналитикам и ПО (во вторую) понять, как лучше взаимодействовать с ИИ.

## Структура документации

Документация разделена на 4 части для удобства использования разными ролями:

### [01. Основы промптинга](01-основы-промптинга.md)

**Для кого:** Все роли (дизайнеры, аналитики, ПО)  
**Содержание:**
- Введение в структурированный промптинг
- Почему это работает (простое и научное объяснение)
- Теоретические основания (8 разделов)
- Общая схема работы структурированного промпта
- Практический пример

**Когда читать:** Начните с этого файла, чтобы понять основы работы с ИИ.

---

### [02. Руководство для дизайнеров](02-руководство-для-дизайнеров.md)

**Для кого:** UX/UI дизайнеры  
**Содержание:**
- Как структурировать промпт для дизайнера
- Шаблоны промптов
- Примеры хороших и плохих промптов
- Чек-лист для проверки промпта
- Использование правил в промптах

**Когда читать:** Если вы дизайнер и хотите научиться создавать эффективные промпты для работы с ИИ.

---

### [03. Руководство для аналитиков и ПО](03-руководство-для-аналитиков-и-по.md)

**Для кого:** Аналитики и Product Owners  
**Содержание:**
- Границы ответственности (кто отвечает за UX/UI)
- Как правильно формулировать запросы дизайнерам
- Что можно делать самостоятельно с ИИ
- Что НЕ нужно делать самостоятельно
- Процесс работы: рекомендуемый workflow
- Частые ошибки и как их избежать

**Когда читать:** Если вы аналитик или ПО и хотите понять, как правильно взаимодействовать с дизайнерами и ИИ, не нарушая границы ответственности.

---

### [04. Справочник правил для ИИ](04-справочник-правил-для-ии.md)

**Для кого:** UX/UI дизайнеры (создание правил), аналитики и ПО (понимание структуры)  
**Содержание:**
- Зачем нужны правила
- Формат правил в Cursor (`.mdc` файлы)
- Примеры правил для дизайн-системы
- Примеры правил для платформенных ограничений
- Примеры правил для UX ограничений
- Структура директории `.cursor/rules/`
- Как создавать правила
- Использование правил в промптах

**Когда читать:** Если вы дизайнер и хотите создать правила для проекта, или если вы хотите понять, как работают правила.

---

## Быстрый старт

### Для дизайнеров:

1. Прочитайте [Основы промптинга](01-основы-промптинга.md) — поймите теорию
2. Изучите [Руководство для дизайнеров](02-руководство-для-дизайнеров.md) — практические шаблоны
3. При необходимости создайте [правила для проекта](04-справочник-правил-для-ии.md)

### Для аналитиков и ПО:

1. Прочитайте [Основы промптинга](01-основы-промптинга.md) — поймите теорию
2. Изучите [Руководство для аналитиков и ПО](03-руководство-для-аналитиков-и-по.md) — границы ответственности
3. Ознакомьтесь со [Справочником правил](04-справочник-правил-для-ии.md) — понимание структуры

---

- Четко разделить ответственность между ролями
- Научить аналитиков и ПО правильно формулировать запросы дизайнерам
- Научить дизайнеров эффективно работать с ИИ
- Создать единые стандарты работы с промптами
